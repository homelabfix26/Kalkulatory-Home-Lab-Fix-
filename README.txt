KALKULATORY HOME LAB&FIX — INSTRUKCJA

Pliki w paczce:
1. index.html — gotowa strona z kalkulatorami.
2. README.txt — ta instrukcja.

Publikacja na GitHub Pages z telefonu:
1. Wejdź na GitHub w przeglądarce.
2. Otwórz repozytorium: Kalkulatory-Home-Lab-Fix-
3. Kliknij: Add file → Upload files.
4. Wgraj plik index.html z tej paczki.
5. Kliknij zielony przycisk: Commit changes.
6. Wejdź w: Settings → Pages.
7. W sekcji Build and deployment wybierz:
   Source: Deploy from a branch
   Branch: main
   Folder: /root
8. Kliknij Save.
9. Po chwili strona powinna działać pod adresem:
   https://homelabfix26.github.io/Kalkulatory-Home-Lab-Fix-/

Publikacja na Netlify z telefonu:
1. Wejdź na https://app.netlify.com/drop
2. Rozpakuj ZIP na telefonie.
3. Wgraj sam plik index.html albo cały folder.
4. Netlify wygeneruje publiczny link automatycznie.

Publikacja na Cloudflare Pages:
1. Wejdź w Cloudflare Dashboard → Workers & Pages.
2. Create application → Pages.
3. Upload assets.
4. Wgraj folder z plikiem index.html.
